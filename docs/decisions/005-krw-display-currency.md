# ADR-005: 금액은 원화(KRW)를 기본으로 보여 주고, 달러로 바꿔 볼 수 있게 한다

- 상태: 승인됨 (2026-10-13, 이슈 #5)

## 배경
사용자는 원화가 익숙하지만 AWS 단가는 달러다. 환율은 매일 바뀐다. 프론트에서 환산하면 계산이 화면에 흩어진다.

## 결정
- 금액 원본(DB, 계산)은 **USD 그대로** 둔다. 응답을 만들 때만 환산한다.
- 조회 API에 `currency=KRW|USD` 파라미터. **기본 KRW**. 프론트의 원 ⇄ 달러 버튼은 같은 API를 currency만 바꿔 다시 부른다 (DB 캐시라 AWS 호출 없음).
- 환율: **Frankfurter**(유럽중앙은행 기준환율, 무료, 키 없음). 영업일마다 갱신, 주말·공휴일은 직전 영업일 값.
  받은 환율은 `exchange_rates`에 저장하고 **6시간** 동안 재사용한다.
- 모든 기간의 금액을 **최근 환율 하나**로 환산한다. 날마다 다른 환율을 쓰면 같은 사용 시간인데 금액이 들쭉날쭉해 보인다.
  응답에 `exchangeRate{rate, date, source}`와 "원화 금액은 YYYY-MM-DD 환율(…)로 환산한 추정치" 안내를 넣는다.
- 환율 API 실패: 마지막 저장 환율 + 안내. 한 번도 받지 못했으면 USD로 응답 + 안내.
- 반올림: KRW 금액 원 단위, 시간당 단가 0.1원 / USD 금액 센트, 단가 소수 넷째 자리.

## 결과
- 사용자 데이터는 환율 API로 나가지 않는다 (통화 코드만 요청).
- 공식 원화 기준(수출입은행 매매기준율)이 필요해지면 `ExchangeRateSource` 어댑터만 바꾼다 (인증키 필요).
- 과거 날짜별 환율 환산은 하지 않는다. 필요하면 `exchange_rates`에 쌓인 날짜별 값을 쓸 수 있다.

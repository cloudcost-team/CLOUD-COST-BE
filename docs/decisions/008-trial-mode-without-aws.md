# ADR-008: 실제 계정 없이 체험하기 (체험 모드)

- 상태: 제안 (2026-11-03, 이슈 #18)

## 배경
- 시연을 보는 사람 대부분은 AWS 계정이 없거나, 그 자리에서 Role을 만들 수 없다. 그래도 "계정을 연결하면 이렇게 보인다"를 직접 해 봐야 한다.
- 절대 규칙 9는 "연결 성공"을 Mock으로 만들지 말라고 한다. 실제 연결 경로에 가짜 성공이 섞이면 실제 사용자의 데이터와 구분할 수 없게 된다.

## 결정
- 실제 연결과 **분리된** 체험 경로 `/api/v1/demo/*`를 둔다. Google 로그인 없이 간이 로그인(`cloudcost` / `1234`, 환경변수로 변경 가능) →
  서버 구성(타입·OS·대수·사용 패턴)과 기간 설정 → 실제 연결과 같은 형식의 비용 응답.
- 간이 로그인은 실제 AWS 자격증명이 아니라 화면에 안내하는 공개 값이다. 토큰·세션을 만들지 않고, 비용 조회는 로그인 없이도 열려 있다(공개 계산기와 같다).
- 체험용 계정은 `aws_accounts`에 저장하지 않는다. 연결 목록·수집·sync에 나타나지 않으며, AWS와 DB를 부르지 않는다.
- 서버 구성을 domain(`DemoFleet`)에서 DescribeInstances 인스턴스 + CloudWatch SampleCount 시간별 샘플 모양으로 만들고,
  실제 조회와 같은 집계·비용 계산(`UsageAggregator`, `CostEstimator`)과 같은 응답 DTO를 거친다. 응답은 `dataSource: "demo"`.
- 단가는 서울 리전 온디맨드 단가 고정표(`DemoCatalog`)를 쓰고, 응답 `notes`에 체험 데이터·예시 단가임을 적는다.

## 결과
- 규칙 9는 그대로다: 실제 연결 경로에는 Mock 성공이 없다. 체험 모드는 `dataSource`와 화면의 "체험 모드" 표시로 항상 구분된다.
- 실제 계산 로직을 그대로 타므로, 계산을 바꾸면 체험 모드 결과도 같이 바뀐다 (응답 형식 일치는 `DemoApiTest`가 확인한다).
- 고정 단가는 실제 Price List 값과 시간이 지나면 달라질 수 있다. 체험용이라 허용한다.
